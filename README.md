# Prompt Engineering Project 1

## Zero-Shot & Few-Shot Data Extraction

This project demonstrates the use of Prompt Engineering techniques to extract structured information from unstructured text and convert it into valid JSON format.

### Key Concepts
- Zero-Shot Prompting
- Few-Shot Prompting
- Delimiters
- Structured Output Generation
- JSON Formatting

### Tools Used
- ChatGPT
- GitHub
- JSON

### Outcome
Successfully extracted hero details such as name, alias, city, and powers from unstructured text while generating consistent JSON outputs across multiple test cases.
